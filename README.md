# A2Rank

AION2의 **랭킹 포인트 변화, 처치·사망 기록, 스킬별 피해**를 보여 주는 윈도우용 비공식 도구입니다.
게임 화면이나 파일을 건드리지 않고, 게임 서버와 주고받는 패킷을 **내 PC에서 읽기만** 합니다. 엔씨소프트와 관계없는 비공식 프로그램입니다.

> 사용으로 생길 수 있는 불이익(계정 제재 등)은 사용자 책임입니다. 게임사 약관을 직접 확인하세요. 자세한 내용: [이용 안내와 면책](TERMS.md)

## 설치
1. **[A2Rank-win-Setup.exe](https://github.com/A2Rank/releases/releases/download/update/A2Rank-win-Setup.exe)** 를 내려받아 실행하세요. (관리자 권한이 필요 없고, 내 계정 폴더에 설치됩니다.)
2. 윈도우가 "PC를 보호했습니다"(SmartScreen) 창을 띄우면 **추가 정보 → 실행**을 누르세요. 프로그램에 아직 코드 서명이 없어서 나오는 안내입니다.
3. 게임을 켠 채로 A2Rank를 실행하면 측정이 시작됩니다.

설치 없이 쓰려면 `A2Rank-win-Portable.zip`을 풀어서 실행해도 됩니다 (자동 업데이트는 설치한 앱만 됩니다).

## 기능
- 이번 시간의 랭킹 포인트 변화, 오늘 누적, 내 랭킹
- 처치 명단 (이 시간에 처치·사망한 상대, 포인트)
- 처치별 피해 통계 (스킬별 피해, 치명타·완벽 등, 받은 회복)
- 내 기록 (구간별 획득·손실 그래프)
- 자동 업데이트 (서명을 확인한 파일만 설치)

자세한 사용법은 프로그램의 **설정 → 사용 설명서**에 있습니다.

## 개인정보
아무것도 보내지 않아도 모든 기능을 쓸 수 있습니다. 서버로 가는 것은 사용자가 동의하거나 직접 누른 경우뿐입니다.
- 이 PC에만 저장: 설정, 기록, 다른 플레이어의 이름(**7일 뒤 자동 삭제**)
- 서버로 보냄(동의한 경우): 구간 기록(내 캐릭터 이름·서버, 포인트 변화. **상대 이름은 보내지 않음**), [데이터 보내기](PRIVACY.md)(직접 누를 때)

전체 내용: [개인정보 처리방침](PRIVACY.md)

## 제거
Windows **설정 → 앱**에서 A2Rank를 제거하거나, 트레이 아이콘 메뉴의 "프로그램 제거…"를 쓰세요. 이때 기록 데이터까지 지울지 물어봅니다.
